# Benconnect – Info & Kontakt

Deutschsprachige, responsive Info- und Kontaktseite für [Benconnect](https://github.com/BG-gmbh/benconnect).

## Inhalt

- Projektvorstellung und Funktionsübersicht
- Kontakt per E-Mail: Contact@benconnect.info
- Links zur Plattform, GitHub-Diskussionen und Fehlermeldungen

## Lokal ansehen

`index.html` im Browser öffnen oder im Repository `python3 -m http.server 8080` starten und http://localhost:8080 aufrufen.

Die Website besteht aus `index.html` und `style.css`. Ein Build oder zusätzliche Pakete sind nicht erforderlich. Die Schriftarten werden über Google Fonts geladen; lokale Ersatzschriften sind definiert.

## Bereitstellung

Die beiden Dateien können direkt auf einem statischen Webserver bereitgestellt werden. Für GitHub Pages kann der Branch `main` mit dem Ordner `/ (root)` ausgewählt werden.
